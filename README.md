# WHM & AABM Tours and Travel

Modern responsive safari website using the original logo, published packages, prices, policies and contact links from https://whmandaabm.com.

## Run locally

Run `node preview.cjs` and open http://127.0.0.1:4173.

## Deploy

Publish the `dist` directory on any static web host. No build step or dependencies are required. The production entry is `dist/index.html`.

## Booking

The three-step form calculates indicative USD totals from published rates and preserves published price ranges. The Gorilla Trekking and Lake Bunyonyi group price applies only to 3+ travelers sharing. Custom itineraries require a personalized quote. Final pricing and availability must be confirmed by the company.

WhatsApp opens a formatted draft addressed to +256 703 023 337. The visitor sends it. No payment or automatic message delivery is performed by this static website.
